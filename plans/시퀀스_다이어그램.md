## 1. 워크플로우 전체 실행 흐름

```mermaid
sequenceDiagram
    actor User as 👤 사용자
    participant UI as 🖥️ UI (app.js)
    participant Server as ⚙️ Express 서버
    participant Orch as 🔄 오케스트레이터
    participant Agent as 🤖 에이전트
    participant Browser as 🌐 Playwright Browser

    User->>UI: 워크플로우 실행 버튼 클릭
    UI->>Server: POST /api/run { workflowId, input }
    Server->>Orch: runWorkflow(workflow, input)
    Orch->>Orch: loadSettings() → context 병합
    Orch->>UI: SSE: workflow_start

    loop 각 스텝 순차 실행
        Orch->>Orch: 변수 치환 ({{prev_output}}, {{workflow_input}} 등)
        Orch->>UI: SSE: step_start
        Orch->>Agent: execute(prompt, options)
        Agent->>Browser: Playwright 자동화 실행
        Browser-->>Agent: 결과 반환
        Agent-->>Orch: 출력값 반환
        Orch->>Orch: context.prev_output 갱신
        Orch->>UI: SSE: step_done
    end

    Orch->>UI: SSE: workflow_done
    UI->>User: 완료 알림 표시
```

## 2. Gemini 프롬프트 실행 시퀀스

```mermaid
sequenceDiagram
    participant Orch as 오케스트레이터
    participant GA as gemini_agent.js
    participant SM as session_manager.js
    participant GC as gemini_compose.js
    participant Gemini as Gemini Web (gemini.google.com)

    Orch->>GA: execute(prompt, options)
    GA->>SM: getOrCreateSession()
    SM-->>GA: Playwright Page (퍼시스턴트 세션)
    GA->>GC: submitPromptAndWait(page, prompt)
    GC->>Gemini: 새 채팅 시작 또는 기존 채팅 재사용
    GC->>Gemini: 프롬프트 텍스트 입력 + 전송
    Gemini-->>GC: 응답 스트리밍 시작
    GC->>GC: 응답 완료 감지 (완료 버튼/상태 폴링)
    GC-->>GA: 응답 텍스트 추출
    GA-->>Orch: 최종 응답값 반환
```

## 3. 네이버 블로그 자동 포스팅 시퀀스

```mermaid
sequenceDiagram
    participant Orch as 오케스트레이터
    participant NBA as naver_blog_agent.js
    participant NP as playwright_naver_publish.js
    participant NE as naver_editor.js
    participant NI as naver_image.js
    participant NaverBlog as 네이버 블로그

    Orch->>NBA: execute(prompt, options)
    NBA->>NBA: JSON 파싱 (title, content, images, visibility)
    NBA->>NBA: 제목 클리닝 (순번 숫자 제거)
    NBA->>NBA: content JSON → tempFile 저장

    NBA->>NP: run({ blogId, naverId, contentFile, images, visibility })
    NP->>NaverBlog: /blog.naver.com/{blogId}?Redirect=Write 접속
    NP->>NaverBlog: 임시저장 팝업 자동 닫기

    NP->>NE: fillEditorFromJson(page, payload)
    NE->>NaverBlog: 제목 타이핑 (CDP 이벤트)
    NE->>NaverBlog: 본문 블록 순차 입력
    NE->>NaverBlog: 소제목 → 인용구 변환 (PASS2)
    NE->>NaverBlog: 형광펜 하이라이트 적용 (PASS3)

    NP->>NI: pasteImagesFromLocal(page, images)
    NI->>NaverBlog: 썸네일 이미지 클립보드 붙여넣기
    NI->>NaverBlog: 본문 이미지 마커 위치에 순차 삽입

    NP->>NaverBlog: 발행 패널 열기
    NP->>NaverBlog: 태그 입력 (25개)
    NP->>NaverBlog: visibility 설정 (공개/이웃/비공개)
    NP->>NaverBlog: 최종 발행 버튼 클릭
    NaverBlog-->>NP: 발행 완료
    NP-->>NBA: SUCCESS
    NBA-->>Orch: { success: true }
```

## 4. 티스토리 자동 포스팅 시퀀스

```mermaid
sequenceDiagram
    participant Orch as 오케스트레이터
    participant TBA as tistory_blog_agent.js
    participant TP as playwright_tistory_publish.js
    participant TEI as tistory_editor_inject.js
    participant TPG as tistory_placeholder_gate.js
    participant KL as kakao_login.js
    participant Tistory as 티스토리

    Orch->>TBA: execute(prompt, options)
    TBA->>TBA: JSON 파싱 (title, content, images, visibility)
    TBA->>TBA: 제목 HTML 태그 검사 후 클리닝
    TBA->>TBA: content → tempFile 저장

    TBA->>TP: run({ blogUrl, kakaoId, kakaoPassword, contentFile, images, visibility })
    TP->>KL: login(page, kakaoId, kakaoPassword)
    KL->>Tistory: 카카오 계정 로그인 자동화
    Tistory-->>KL: 로그인 성공

    TP->>Tistory: 글쓰기 에디터 접속
    TP->>TEI: injectHtmlToTistoryEditor(page, html)
    TEI->>Tistory: 제목 입력
    TEI->>Tistory: 본문 HTML 직접 주입

    TP->>TP: 이미지 처리 (썸네일 / 본문 플레이스홀더 교체)
    TP->>Tistory: 로컬 이미지 업로드 (파일 업로드 API)

    TP->>TPG: triggerTistoryPublishLayerFlow(page, { visibility })
    TPG->>Tistory: #publish-layer-btn 클릭
    TPG->>Tistory: visibility 라디오 버튼 선택
    Note over TPG, Tistory: 0: 비공개 / 1: 공개(보호) / 2: 전체공개
    TPG->>Tistory: 발행 확인 버튼 클릭

    Tistory-->>TP: 발행 완료 URL 획득
    TP-->>TBA: SUCCESS
    TBA-->>Orch: { success: true, url }
```

## 5. Gemini 이미지 생성 시퀀스

```mermaid
sequenceDiagram
    participant Orch as 오케스트레이터
    participant GIA as gemini_image_agent.js
    participant GI as gemini_image.js
    participant SM as session_manager.js
    participant Gemini as Gemini Web

    Orch->>GIA: execute(prompt, options)
    GIA->>GIA: JSON 파싱 { text, style, title }

    Note over GIA: title 파라미터로 썸네일 주제 결정<br>(HTML 본문 H1 추출 fallback)

    GIA->>GIA: prompts[] 생성<br>- thumbnail (대표 이미지)<br>- imgplace × N (본문 이미지)

    loop 각 이미지 프롬프트
        GIA->>GI: generateImage(prompt, style)
        GI->>SM: getOrCreateSession()
        SM-->>GI: Playwright Page
        GI->>Gemini: 이미지 생성 프롬프트 전송
        Gemini-->>GI: 생성된 이미지 반환
        GI->>GI: 로컬 파일 저장 (temp_images/)
        GI-->>GIA: { localPath, type, marker }
    end

    GIA-->>Orch: { success: true, images: [...] }
```

## 6. 세션 관리 시퀀스

```mermaid
sequenceDiagram
    participant Agent as 에이전트
    participant SM as session_manager.js
    participant GS as gemini_session.js
    participant Profile as Playwright Profile (로컬 디스크)
    participant Browser as Chromium 브라우저

    Agent->>SM: getOrCreateSession()
    SM->>SM: 기존 세션 확인

    alt 기존 세션 존재
        SM-->>Agent: 기존 Page 반환
    else 신규 세션 생성
        SM->>GS: createSession(profilePath)
        GS->>Profile: 퍼시스턴트 컨텍스트 로드
        GS->>Browser: Chromium 실행 (headless or headful)
        Browser-->>GS: 브라우저 컨텍스트 생성
        GS->>Browser: Google 로그인 상태 확인
        Browser-->>GS: 로그인 완료 (쿠키 재활용)
        GS-->>SM: Page 반환
        SM-->>Agent: 새 Page 반환
    end
```
