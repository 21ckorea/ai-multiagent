## 1. 전체 유스케이스 개요

```mermaid
graph LR
    User(["👤 사용자"])

    subgraph System["AI 멀티에이전트 오케스트레이터"]
        direction TB

        subgraph UC_WORKFLOW["워크플로우 관리"]
            UC1["워크플로우 생성 / 편집 / 삭제"]
            UC2["스텝 추가 / 순서 변경"]
            UC3["루프(반복) 조건 설정"]
            UC4["워크플로우 내보내기 / 가져오기"]
        end

        subgraph UC_PROMPT["프롬프트 관리"]
            UC5["스텝 프롬프트 작성 / 편집"]
            UC6["변수 {{변수명}} 삽입"]
            UC7["플러그인 타입 선택"]
        end

        subgraph UC_SETTINGS["접속 정보 설정"]
            UC8["환경변수 등록 / 수정"]
            UC9["비밀번호 마스킹 설정"]
            UC10["설명(비고) 작성"]
        end

        subgraph UC_RUN["실행 & 모니터링"]
            UC11["워크플로우 실행"]
            UC12["실시간 로그 확인(SSE)"]
            UC13["실행 중단"]
            UC14["단계별 결과 확인"]
        end

        subgraph UC_POSTING["자동 포스팅"]
            UC15["네이버 블로그 자동 포스팅"]
            UC16["티스토리 자동 포스팅"]
            UC17["발행 공개 범위 설정"]
            UC18["이미지 자동 생성 및 삽입"]
            UC19["썸네일 대표 이미지 설정"]
        end

        subgraph UC_GEMINI["Gemini 연동"]
            UC20["Gemini 세션 연결"]
            UC21["글 작성 프롬프트 실행"]
            UC22["이미지 생성 프롬프트 실행"]
        end

        subgraph UC_SHEET["Google Sheets 연동"]
            UC23["시트 데이터 읽기"]
            UC24["결과값 시트에 쓰기"]
        end
    end

    User --> UC1
    User --> UC5
    User --> UC8
    User --> UC11
    User --> UC15
    User --> UC16
    User --> UC20
    User --> UC23
```

```mermaid
        T2["이미지 생성 스텝 실행<br>(plugin_gemini_image)"]

    User --> T1
```

## 5. 접속 정보 & 환경변수 유스케이스

```mermaid
graph LR
    User(["👤 사용자"])

    subgraph Settings["접속 정보 설정"]
        S1["변수 추가<br>(변수명 / 값 / 설명)"]
        S2["비밀번호 마스킹<br>(비밀번호 여부 체크)"]
        S3["설명(비고) 자동 완성<br>(사전 정의 변수명 입력 시)"]
        S4["설정 저장<br>(data/settings.json)"]
        S5["워크플로우 실행 시<br>{{변수명}} 자동 치환"]
    end

    subgraph PreDefined["사전 정의 변수"]
        V1["blogUrl: 티스토리 블로그 주소"]
        V2["kakaoId: 카카오 계정 ID"]
        V3["kakaoPassword: 카카오 비밀번호 🔒"]
        V4["blogId: 네이버 블로그 ID"]
        V5["naverId: 네이버 로그인 ID"]
        V6["blogAlias: 네이버 블로그 별칭"]
        V7["tistoryAlias: 티스토리 별칭"]
        V8["naverVisibility: 네이버 공개 설정"]
        V9["tistoryVisibility: 티스토리 공개 설정"]
    end

    User --> S1
    S1 --> S2

    S3 --> V1
```
