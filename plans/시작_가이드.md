# 🚀 AI 멀티에이전트 오케스트레이터 — 시작 가이드

> 이 문서는 처음 사용하시는 분들을 위한 **단계별 설치 및 시작 안내서**입니다.  
> 순서대로 따라 하시면 누구든 5분 안에 시작하실 수 있습니다! 😊

---

## 📋 시작 전 확인사항

아래 항목을 미리 준비해 주세요.

| 항목 | 설명 |
|---|---|
| **Google 계정** | Gemini 웹 사용을 위한 구글 계정 |
| **네이버 계정** | 네이버 블로그 포스팅용 계정 |
| **카카오 계정** | 티스토리 로그인용 카카오 계정 |
| **네이버 블로그 주소** | 예: `trend_signal` (블로그 ID) |
| **티스토리 블로그 주소** | 예: `https://today-ittrend.tistory.com` |

## ✅ STEP 1 — 프로그램 설치

### Windows 사용자

1. GitHub Releases 페이지 또는 공유받은 폴더에서 설치 파일을 다운로드합니다.
   ```
   AI-Multiagent Setup 1.0.0.exe
   ```
2. 다운로드한 `.exe` 파일을 **더블클릭**하여 설치를 시작합니다.
3. "Windows가 PC를 보호했습니다" 메시지가 나타나면 → **추가 정보** → **실행** 을 클릭합니다.
4. 설치 완료 후 바탕화면에 생성된 **AI 멀티에이전트 오케스트레이터** 아이콘을 클릭하여 실행합니다.

### macOS 사용자

1. 공유받은 폴더에서 `.dmg` 또는 `.zip` 파일을 다운로드합니다.
2. 파일을 열고 앱을 **응용 프로그램(Applications)** 폴더로 드래그합니다.
3. 처음 실행 시 "확인되지 않은 개발자" 경고가 뜨면:
   - **시스템 설정** → **개인 정보 보호 및 보안** → **확인 없이 열기** 클릭

> [!TIP]
> 프로그램이 정상 실행되면 좌측 하단에 **서버 연결됨** (초록 점)이 표시됩니다.

---

## ✅ STEP 2 — 설정 파일 가져오기

처음 실행하면 워크플로우와 스텝 설정이 비어 있습니다.  
미리 준비된 **설정 파일(백업 파일)**을 불러오면 모든 워크플로우가 한 번에 셋팅됩니다.

### 순서

1. 프로그램 왼쪽 메뉴에서 **🔄 워크플로우** 탭을 클릭합니다.
2. 하단의 **`가져오기`** 버튼을 클릭합니다.

   ```
   📁 버튼 위치: 화면 왼쪽 하단 → 💾 내보내기 / 📂 가져오기
   ```

3. 파일 탐색기가 열리면 아래 경로의 최신 설정 파일을 선택합니다.

   ```
   📁 ai-multiagent/
   └── 📁 config/
       └── 📄 ai_multiagent_backup_2026-07-26.json  ← 이 파일 선택!
   ```

4. **열기** 버튼을 클릭하면 워크플로우와 스텝이 자동으로 불러와집니다.

> [!NOTE]
> 설정 파일 이름에서 날짜(`2026-07-26`)는 백업 날짜입니다. 가장 최근 날짜의 파일을 선택하세요.

---

## ✅ STEP 3 — 접속 정보 설정

워크플로우가 자동으로 블로그에 포스팅하려면 **계정 정보와 블로그 설정**을 먼저 입력해야 합니다.

### 순서

1. 왼쪽 메뉴에서 **🔑 접속 정보 설정** 탭을 클릭합니다.
2. 각 변수명에 맞는 값을 입력합니다.

---

### 📝 입력 항목 안내

| 변수명 | 입력할 값 | 예시 |
|---|---|---|
| `blogUrl` | 티스토리 블로그 전체 주소 | `https://today-ittrend.tistory.com` |
| `kakaoId` | 티스토리 로그인용 카카오 이메일 | `hong@naver.com` |
| `kakaoPassword` | 카카오 계정 비밀번호 🔒 | `●●●●●●●●` |
| `blogId` | 네이버 블로그 ID | `trend_signal` |
| `naverId` | 네이버 로그인 ID | `hong1234` |
| `blogAlias` | 네이버 블로그에서 사용할 필명 | `홍길동 소장` |
| `tistoryAlias` | 티스토리에서 사용할 필명 | `홍길동` |
| `naverVisibility` | 네이버 블로그 발행 공개 범위 | `2` |
| `tistoryVisibility` | 티스토리 발행 공개 범위 | `0` |

---

### 🔓 발행 공개 설정값 안내

**네이버 블로그** (`naverVisibility`)

| 값 | 의미 |
|---|---|
| `0` | 🔒 비공개 |
| `1` | 👥 이웃공개 |
| `2` | 🌐 전체공개 (기본값 권장) |
| `3` | 🤝 서로이웃공개 |

**티스토리** (`tistoryVisibility`)

| 값 | 의미 |
|---|---|
| `0` | 🔒 비공개 (초안으로 저장, 테스트 시 권장) |
| `1` | 🔑 공개(보호) — 비밀번호 있는 글 |
| `2` | 🌐 전체공개 |

> [!TIP]
> 처음 테스트할 때는 `naverVisibility`와 `tistoryVisibility` 모두 **`0` (비공개)**으로 설정하는 것을 권장합니다.  
> 포스팅 결과를 확인한 뒤 `2` (전체공개)로 변경하세요.

3. 입력이 완료되면 **`💾 설정 저장`** 버튼을 클릭합니다.
4. "✓ 설정이 정상적으로 저장되었습니다." 메시지가 나타나면 완료입니다.

## ✅ STEP 4 — Gemini 세션 연결

네이버/티스토리 포스팅 전에 **Gemini와 연결**하여 글 작성을 준비해야 합니다.

### 순서

1. 왼쪽 메뉴에서 **✨ Gemini 연결** 탭을 클릭합니다.
2. **`Gemini 연결 시작`** 버튼을 클릭합니다.
3. 크롬 브라우저가 자동으로 열리면서 `gemini.google.com` 페이지로 이동합니다.
4. 구글 계정으로 **로그인을 완료**합니다.
5. 로그인 후 프로그램 화면으로 돌아오면 좌측 상단에 **연결됨 (초록 점)**이 표시됩니다.

> [!IMPORTANT]
> 한번 로그인하면 세션이 저장되므로 다음 실행 시에는 로그인이 자동으로 유지됩니다.

---

## ✅ STEP 5 — 워크플로우 실행하기

이제 모든 준비가 완료되었습니다! 워크플로우를 실행하여 자동으로 블로그 글을 작성하고 포스팅해 봅니다.

### 순서

1. 왼쪽 메뉴에서 **▶️ 실행 & 모니터링** 탭을 클릭합니다.

2. **워크플로우 선택** 드롭다운에서 실행할 워크플로우를 선택합니다.

   ```
   예시 워크플로우 목록:
   ✅ 네이버 블로그 자동 포스팅
   ✅ 티스토리 자동 포스팅
   ✅ 네이버 + 티스토리 동시 포스팅
   ```

3. **입력값** 란에 포스팅할 **블로그 글 제목 또는 주제**를 입력합니다.

   ```
   입력 예시:
   ✏️ "딥시크 V3 API 비용 절감 방법 완전 정리"
   ✏️ "챗GPT Plus 구독 vs 무료 버전 비교 2026"
   ✏️ "공무원 AI 보고서 작성 프로그램 추천"
   ```

4. **`▶️ 실행 시작`** 버튼을 클릭합니다.

5. 아래 **로그 창**에서 실시간으로 진행 상황을 확인합니다.

---

### 📊 실행 중 로그 확인 방법

| 로그 메시지 | 의미 |
|---|---|
| `━━━ [1/4] 스텝명 ━━━` | 해당 번호의 스텝이 시작됨 |
| `🔄 Gemini 호출 준비 중...` | Gemini에 프롬프트 전송 중 |
| `✅ 완료` | 해당 스텝이 정상 완료됨 |
| `[NAVER] editor frame score=...` | 네이버 에디터 연결 성공 |
| `[RESULT: SUCCESS]` | 포스팅 발행 완료 |
| `🎉 워크플로우 완료!` | 모든 스텝이 성공적으로 완료됨 |

## 🔧 자주 묻는 질문 (FAQ)

### Q. 프로그램이 처음 실행 시 잠시 멈추는 것 같아요.
> 처음 실행 시 Playwright 브라우저 엔진을 초기화하는 시간이 필요합니다. 약 10~20초 기다리면 정상적으로 시작됩니다.

### Q. "서버 연결됨" 표시가 안 나타나요.
> 프로그램을 완전히 닫고 다시 실행해 보세요. 만약 계속 안 된다면 방화벽이나 백신 프로그램에서 포트 `3000`을 허용해 주세요.

### Q. Gemini 로그인 창이 자동으로 닫혀버려요.
> **Gemini 연결** 화면에서 **포그라운드(창 표시)** 모드를 선택하고 다시 시도해 보세요. 창이 닫히기 전에 로그인을 완료하면 됩니다.

### Q. 네이버/티스토리 로그인 팝업이 뜨면 어떻게 하나요?
> 포스팅 실행 시 **포그라운드(창 표시)** 모드를 선택하면 브라우저 창이 열립니다. 로그인이 필요한 경우 직접 입력해 주세요. 이후에는 세션이 저장되어 자동 로그인됩니다.

### Q. 포스팅이 완료되었는데 글이 안 보여요.
> `naverVisibility` 또는 `tistoryVisibility` 값이 `0`(비공개)으로 설정되어 있을 수 있습니다. 각 블로그 관리자 페이지에서 해당 글을 찾아 공개로 변경하거나, 접속 정보 설정에서 값을 `2`(전체공개)로 변경 후 재실행해 보세요.

### Q. 이미지가 잘못된 위치에 들어가요.
> 이미지 자동 삽입은 글 작성 프롬프트에서 `이미지 삽입공간 : 설명` 형식의 마커를 기준으로 작동합니다. 프롬프트 설정이 올바른지 확인해 주세요.

### Q. 설정 파일을 실수로 지웠어요.
> `config/` 폴더 안의 백업 파일(`ai_multiagent_backup_날짜.json`)을 다시 **가져오기**하면 복구됩니다.
